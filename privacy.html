Privacy Policy

Agentic Google MCP · Last updated: October 2026

Agentic Google MCP is a personal tool operated by one individual, for their own use, on infrastructure they control. It is connected only to the operator's own Google account.

Google user data the app accesses

  • Gmail (gmail.modify): reads message headers, bodies and attachments, and marks messages as read. The app does not send, delete or draft email.
  • Google Calendar (calendar.readonly): reads event details. It does not create or change events.

How the data is used

Data is fetched only when the operator asks their AI assistant for it (for example, to summarize school emails) and is used solely to provide that result to the operator. Message and event content is not stored by the app after the request completes. The only thing kept is the OAuth refresh token, stored as a secret on the operator's own server.

Sharing

Google user data is not sold, not used for advertising, and not shared with other people or services, except that content may be processed by the AI language model the operator chooses to use for summarization. Data is never used to build or train general-purpose AI models by this app.

Google API Services User Data Policy

{{APP_NAME}}'s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

The operator can revoke the app's access at any time at myaccount.google.com/permissions and can delete the stored token by deleting the corresponding server secret.
